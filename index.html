Hazard Checklist

Check what applies today
Traffic exposure / intrusion risk
Work zone set per TCP; escape path; TCS coordination; TMC call-in as required
Mobile equipment interaction
Pedestrian separation, defined travel paths, eye contact rules, spotter assignments
Backing operations
Backup alarms functional; spotter; no backing without signal
Excavation / trenching
Utility clearance; protective system; competent person; spoil placement; access/egress
Overhead hazards / power lines
Minimum clearance; dedicated spotter if needed; staging plan
Hot work / asphalt / burns
Heat-resistant PPE; safe fueling; extinguisher; skin exposure controls
Heat illness exposure
Water, shade, recovery plan, high heat triggers, buddy system
Night work / low visibility
Lighting plan; Class 3 hi-vis; beacon check; glare control
Public interface
Barrier line, safe routing, clear signage, public complaint routing
HazMat / silica / dust / chemicals
SDS available; labeling; exposure controls; wet methods; respirators if required
